# 📱 PhonePe Pulse – Data Visualization and Exploration

## 📌 Project Overview
PhonePe Pulse is a data visualization project that explores digital payment trends across India using transaction and user data from 2018 to 2022.

The project uses Tableau to create interactive dashboards that help understand transaction patterns, state-wise performance, district-level activity, and mobile brand usage.

## 🎯 Objectives
- Analyze digital payment trends across India.
- Explore state-wise and district-wise transactions.
- Identify popular transaction categories.
- Study registered user growth.
- Visualize mobile brand usage.
- Present meaningful insights through interactive dashboards.

## 🛠️ Tools and Technologies
- **Tableau Public** – Interactive dashboards and data visualization.
- **Microsoft Excel** – Dataset preparation and organization.
- **GitHub** – Project storage and documentation.
- **CSV / Excel** – Dataset formats.

## 📂 Dataset Description
The project contains six prepared datasets:

| Dataset | Description |
|---|---|
| Aggregated Transaction | State-wise transaction details |
| Aggregated User | User and mobile brand information |
| Map Transaction | District-level transaction details |
| Map User | District-level registered users |
| Top Transaction | Top-performing transaction regions |
| Top User | Top-performing user regions |

**Dataset period:** 2018–2022.

## 📊 Dashboard Features
- Interactive state-wise transaction map.
- District-level transaction map.
- District-level registered user map.
- Transaction type analysis.
- Year-wise transaction trends.
- Year-over-year growth analysis.
- Mobile brand usage analysis.
- Top 10 transaction states and districts.
- Top 10 user states and districts.
- KPI cards for total transaction amount, transaction count, registered users, and states.
- Interactive filters for year, quarter, state, transaction type, and brand.

## 🔍 Key Insights
- Digital payment activity increased significantly between 2018 and 2022.
- Transaction values and counts vary across states and districts.
- Peer-to-peer and merchant payments are important transaction categories.
- Registered users and mobile brand usage show changing adoption patterns.

## 📝 Conclusion
This project demonstrates how data visualization can be used to explore India's digital payment ecosystem. The interactive Tableau dashboard helps users identify trends, compare regional performance, and understand digital payment adoption.
